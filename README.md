# 🐧 Penguin Skating Game

A fun and interactive penguin skating game built with HTML and JavaScript!

## How to Play

1. **Open `index.html`** in your web browser
2. **Use Arrow Keys** (← →) to move the penguin left and right
3. **Catch Fish** to score points
4. **Don't lose all 3 lives!**

## Features

- 🐧 Cute penguin character on ice
- 🐟 Moving fish to catch
- 📊 Score tracking system
- ❄️ Animated snowflakes
- 🎮 Smooth controls with arrow keys
- 🎨 Beautiful winter-themed graphics
- 📈 Progressive difficulty (fish spawn faster as you score)

## Game Mechanics

- Catch each fish for **10 points**
- Fish move randomly on the ice
- Game speed increases as your score goes up
- Lives system to keep track of game state

## Files

- `index.html` - Main game file with HTML and CSS
- `game.js` - Game logic and controls
- `README.md` - This file
